# PDF Sales Reports

Генератор PDF-отчётов по продажам для «директора, которому лень открывать Excel». Кидаешь в бота команду — получаешь готовый PDF: выручка, маржинальность, топ-10 товаров таблицей, два графика.

Работает и как **CLI-скрипт** (без Telegram вообще), и как **бот**.

## Как запустить

```bash
python -m venv .venv
pip install -r requirements.txt
python generate_mock_data.py     # сгенерировать sales.csv (1200 строк, для примера)
```

### CLI

```bash
python report.py --input sales.csv --output report.pdf --chart top10.png
```

### Бот

```bash
export WB_BOT_TOKEN=123456:ABC...
python bot.py
```

Команды: `/report` — PDF целиком, `/chart` — только график, `/stats` — цифры текстом. На Windows — `run_bot3.cmd`.

## Из чего состоит

```
report.py           — вся «математика»: чтение CSV, агрегаты, графики, PDF
generate_mock_data.py — генератор тестовых данных (продажи по дням, категории)
bot.py              — команды /report /chart /stats
middlewares.py      — троттлинг и логирование
config.py           — настройки
tests/              — 7 тестов (выручка, топ-10, категории, CLI, PDF-содержимое)
```

## Как устроен отчёт

1. **pandas читает CSV по чанкам** (`chunksize=...`), агрегаты считаются инкрементально. Это осознанное решение: выгрузка на сотни МБ не должна ронять память.
2. **matplotlib** — два графика: топ-10 товаров по выручке и динамика выручки по дням.
3. **reportlab (Platypus)** — собирает PDF: текст + таблица топ-10 с долями и итоговой строкой + графики.
4. **aiogram** — отправляет файл.

## Грабли

- **Шапку таблицы в PDF я сначала построил вертикально** — одна строка на каждый заголовок вместо одной строки-шапки. Выглядело как оглавление. Поймал это код-ревью, а не глазами. С тех пор проверил: таблица собирается строками, `# | Товар | Выручка | Доля`.
- **Кириллица в PDF** — reportlab без TTF-шрифта рисует квадратики. Подключён стандартный шрифт с кириллицей (DejaVu), это указано в коде.
- CSV от «CRM» бывает с запятыми в числах и BOM — парсинг об этом помнит.
