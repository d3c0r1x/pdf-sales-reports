# PDF Sales Reports

Генератор PDF-отчётов по продажам: выручка, маржинальность, топ-10 товаров таблицей, два графика. Поддерживает работу в двух режимах: **CLI-скрипт** (без Telegram) и **бот**.

## 🕹 Живое демо

Попробовать вживую: **[@dfs12f_bot](https://t.me/dfs12f_bot)** — демо-бот портфолио на общем токене.
Локальный запуск — `run_bot3.cmd` (см. раздел «Запуск»). Примечание: в портфолио один токен на все боты, поэтому одновременно в сети может находиться только один проект.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
python generate_mock_data.py     # сгенерировать sales.csv (1200 строк, для примера)
```

### CLI

```bash
python report.py --input sales.csv --output report.pdf --chart top10.png
```

### Бот

```bash
export WB_BOT_TOKEN=123456:ABC...
python bot.py
```

Команды: `/report` — PDF целиком, `/chart` — только график, `/stats` — цифры текстом. На Windows — `run_bot3.cmd`.

## Структура проекта

```
report.py           — обработка данных: чтение CSV, агрегаты, графики, PDF
generate_mock_data.py — генератор тестовых данных (продажи по дням, категории)
bot.py              — команды /report /chart /stats
middlewares.py      — троттлинг и логирование
config.py           — настройки
tests/              — 7 тестов (выручка, топ-10, категории, CLI, PDF-шрифт)
```

## Устройство отчёта

1. **pandas читает CSV по чанкам** (`chunksize=...`), агрегаты считаются инкрементально. Такая схема обеспечивает обработку выгрузок объёмом в сотни МБ без роста потребления памяти.
2. **matplotlib** — два графика: топ-10 товаров по выручке и динамика выручки по дням.
3. **reportlab (Platypus)** — сборка PDF: текст + таблица топ-10 с долями и итоговой строкой + графики.
4. **aiogram** — отправка файла.

## Технические особенности

- **Построение шапки таблицы.** Первоначально шапка строилась вертикально — одна строка на каждый заголовок вместо одной строки-шапки; результат выглядел как оглавление. Дефект выявлен в ходе код-ревью. Текущая версия собирает таблицу строками: `# | Товар | Выручка | Доля`.
- **Кириллица в PDF.** Стандартные шрифты reportlab (Helvetica) не содержат кириллицу: проверка таблицы кодировки WinAnsi показала отсутствие всех 16 букв строки «ТоварВыручкаДоля». Русский текст в PDF отображался некорректно. Решение: подключён TTF-шрифт DejaVu Sans из поставки matplotlib (уже входит в зависимости, загрузка не требуется) и зарегистрирован в reportlab вместе с жирным начертанием для шапки таблицы. Кириллица отображается корректно: и заголовки, и товары.
- CSV читается с разделителем «;», BOM (генератор пишет utf-8-sig) pandas срезает автоматически.

## Планы развития

- отчёт за произвольный период (`--from --to`);
- сравнение месяц к месяцу;
- кэширование сгенерированного PDF.

## Тесты

`pytest tests/ -q` — 7 тестов, включая проверку встроенного шрифта с кириллицей. GitHub Actions прогоняет их при каждом push.
