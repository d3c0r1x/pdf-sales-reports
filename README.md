# Генератор PDF-отчётов для менеджеров (Проект 3)

Скрипт читает CSV с продажами (mock-выгрузка из CRM), считает выручку и
маржинальность, строит графики и генерирует PDF-отчёт с таблицей топ-10. Бот
отправляет готовый PDF «директору» (в любой чат).

## Стек (строго по ТЗ)

| Библиотека | Зачем                                              |
|------------|----------------------------------------------------|
| pandas     | чтение CSV (по чанкам), расчёт выручки и маржи     |
| matplotlib | графики: топ-10 товаров + динамика выручки по дням |
| reportlab  | генерация PDF (Platypus: текст + таблица + графика)|
| aiogram    | отправка PDF в Telegram                            |

CSV читается **по чанкам** (`pandas.read_csv(chunksize=…)`) — агрегаты считаются
инкрементально, поэтому память не растёт с размером файла (выгрузка на сотни МБ
не вызовет MemoryError).

## Команды

- `/report` — сгенерировать и отправить PDF-отчёт
- `/chart` — отправить график PNG отдельно
- `/stats` — текстовая сводка показателей без генерации PDF

## Запуск без бота (CLI)

```bash
pip install -r requirements.txt
python report.py --input sales.csv --output report.pdf --chart top10.png
```

`report.py` сам генерирует mock-CSV, если его нет (`generate_mock_data.py` —
симуляция выгрузки из CRM, как в ТЗ).

## Запуск с ботом

```bash
export WB_BOT_TOKEN=123456:ABC...
python bot.py             # команда /report — сгенерировать и отправить отчёт
```

## Продвинутый уровень (v2)

- **Два разреза аналитики**: топ-10 товаров (barh) + динамика выручки по дням
  (line с заливкой) в одной фигуре; **выручка по категориям** — новые столбцы
  `category` в mock-данных (1200 строк за 180 дней, детерминированный seed);
- **Таблица топ-10 в PDF** (reportlab `Table` + `TableStyle`): ранги, доли,
  итоговая строка и шапка — выглядит как настоящий бизнес-отчёт;
- **CLI на argparse** (`--input/--output/--chart`) — отчёт можно генерировать
  в cron без бота;
- **Middlewares**: троттлинг и логирование;
- **Операции**: `pyproject.toml`, `Dockerfile` (с кириллическими шрифтами для
  графиков), GitHub Actions CI.

Тесты: `pytest tests/ -q` (7 тестов: агрегация с разрезом по дням/категориям,
PDF и PNG, CLI, генератор данных).
